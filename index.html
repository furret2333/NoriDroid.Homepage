01About80 m · 透光层

初次见面时，她什么都不记得

刚装好的 NoriDroid 里，Nori 没有人设、没有声音，也没有形体。这不是 bug，是有意的设计：人格来自你导入的提示词，声音来自你接入的语音服务，形体要你亲手下载。

NoriDroid 是《I_Nori》的同人二创，一个住在 Android 手机里的 Live2D 陪伴应用。它由小桧在 DeepEr（洱海与亓才孑的最初版本）的基础上大规模重制，前前后后做了一个月。起因嘛，是想随时随地摸摸 Nori 的头。

她能陪你做的事

主窗口、退出后的悬浮窗、悬浮窗里的聊天气泡 —— 三个界面，同一个 Nori。

主角

一只随时在线的 Live2D 桌宠

摸摸她的头，她会害羞、会说话。按返回键退出后，她会变成悬浮窗留在桌面上，点一下就能聊天。

  • 摸头有表情、台词、粒子和合成音反馈，头部会跟着你的手指转
  • 可以在模型上框选自定义触摸区域，触发你写好的提示
  • 悬浮窗可拖动、双指缩放，点一下身体弹出聊天气泡
  • 渲染分辨率与帧率上限可调：省电还是清晰，由你决定
  • 两套外观：「潮汐玻璃」与「柔和雾面」

流式对话

接入任意 OpenAI 兼容接口（如 DeepSeek），回复逐字流出。AI 在回复末尾附带表情与动作标记，实时驱动她的神情；也可以让她知道现在几点。

OpenAI 兼容 · 表情标记 · 时间感知

长期记忆

聊得多了会自动总结，AI 从中挑出值得记住的事，合并重复、作废改口的旧说法；对话前按语义召回相关记忆。「记忆库」里可以搜索、置顶、淡忘和恢复。

历史总结 · 语义召回 · 记忆库

03First Contact1,000 m · 无光层

第一次见面

首次打开 App 会自动弹出新手引导，之后也能在「设置」顶部的「新手引导 / 致谢」里重新打开。下面是同样的流程，按顺序来就不会卡住。

  1. 安装

    下载 APK 并安装，需要允许「安装未知来源应用」。要求 Android 7.0 及以上。

    NoriDroid v2.0.0 · 5.4 MB 全部版本与更新说明
    SHA-256 2c3db3beb2911c7aa1abe84dfc4827f5c4ffdc6cb66480184eb5a176ba498042

  2. 授权存储

    设置 › 数据与存储 › 所有文件访问权限 ›「去授权」

    Android 11 起，聊天、记忆和日记都存在公共下载目录，没有这个权限，卸载重装后会读不到原来的内容。读不到时，点同一处的「存储自检」排查。

  3. 接入大模型

    设置 › 连接与人设 › API Base URL / API Key ›「加载模型」

    任何 OpenAI 兼容接口都可以（必须是 HTTPS），例如 DeepSeek 填 https://api.deepseek.com。API 需要你自己在服务商那里开通并付费。

  4. 导入人设

    设置 › 连接与人设 ›「人设文案（提示词）」›「导入文件」

    选择 UTF-8 编码的 .md / .txt（不超过 200 KB）。人设保存在本机，只会作为提示词随对话发给你填写的 API。原版提示词可以在群里找到。

  5. 下载形体

    底栏「模型」或左上角的模型名 › ARGNori / Nori

    首次下载要先答对「模型授权验证」里的问题。模型包十几 MB。

  6. 给她声音 可选

    设置 › 连接与人设 ›「语音合成」

    选择 Fish Audio 或千问 CosyVoice，填入对应的 API Key。引导里推荐千问的 Audio 3.1（qwen-audio-3.1-tts-flash），效果与价格都不错；也可以克隆你喜欢的声音。

  7. 声音与陪伴 可选

    设置 › 声音与陪伴 ›「下载音效」/「下载背景音乐资源」

    音效包含按键音与番茄钟铃声；背景音乐约 13 MB。想让她在退出后留在桌面，去「窗口与手势」打开「退出后显示悬浮窗 Nori」，首次需要授予悬浮窗权限。

网络模型与音频资源托管在静态存储上，国内网络不一定能直连，下载前请先准备好网络环境。

别忘了设置改完，记得点底部的「保存设置」。

常见问题

装好以后，Nori 为什么没有性格，也不说话？

这是有意的设计。她要先接上一个大模型 API（第 3 步）才能回话，导入人设（第 4 步）之后才有人格；声音和形体也要分别接入、下载。

要花钱吗？

NoriDroid 本身免费开源，本项目不提供任何收费服务。对话（LLM）和语音（TTS）需要你自己在服务商那里开通 API，费用由你和服务商结算。

卸载会丢数据吗？

聊天记录、记忆、日记、设置和人设存在 Download/NoriDroid/，卸载后一般仍在（系统询问是否保留应用数据时，勾选保留更保险）。重装后授予「所有文件访问权限」即可读回。

Live2D 模型、音效、背景音乐和参考音频缓存存在应用私有目录，卸载会被清除，需要重新下载；API Key 存在系统 Keystore 保护的私有存储里，也需要重新填写。

为什么下载模型前要答题？

ARGNori、Nori 两个模型和一键克隆用的内置参考音频由 inori 提供，因为特殊性不能直接分发。答对题目（「Nori 写的诗第一句？」）才会解锁下载。答不上来的话，可以去群里问问。

为什么需要「所有文件访问权限」？

Android 11 起，公共下载目录里由其他应用写入的文件 —— 包括卸载前的 NoriDroid 自己 —— 新装的应用既看不到也读不了。这个权限用来读写 Download/NoriDroid/ 里的数据文件，让你的聊天、记忆和日记在重装后还能读回来。

模型或音效一直下载失败？

多半是网络问题：资源托管在静态存储（IPFS）上，国内网络不一定能直连。换个网络环境再试；还是不行的话，带上截图到群里或 GitHub Issues 反馈。

有 iOS 或电脑版吗？

NoriDroid 只有 Android 版。桌面版（Tauri）请看上游项目 erhiolab/DeepEr。

这是官方应用吗？

不是。NoriDroid 是社区同好自发维护的非官方、非商业开源项目，与《I_Nori》官方团队及其母公司没有商业关联或从属关系。喜欢 Nori 的话，欢迎把正作 《I_NORI》加入 Steam 愿望单。

04Privacy3,000 m · 无光层

隐私与数据

NoriDroid 没有自己的后端服务器。对话与语音请求直接发往你填写的服务商，资源文件从静态托管下载。

会联网的地方

  • 对话你的消息、人设和相关记忆，发往你填写的 LLM 接口
  • 朗读要朗读的文本，发往你选择的语音服务（Fish Audio / 千问）
  • 一键克隆下载内置参考音频，再上传给千问做音色克隆
  • 资源下载Live2D 模型、音效和背景音乐，只下载、不上传

不会做的事

  • 没有统计、广告或崩溃上报 SDK
  • API Key 只存在本机，由 Android Keystore 保护
  • 不在任何项目服务器上保存你的数据

关于「海」的笔记

NoriDroid 的不少细节 —— 数据海、记忆、那句「请在呼唤中重新认识我一次」—— 都与《I_Nori》ARG 的世界观相互呼应。这里留了一份社区解读。

FT-ARCHIVE
COLD 剧透警告含《I_Nori》ARG 剧情的大量剧透。以下为同人解读，不代表官方设定。 使用 QFR-9000 恢复档案
QFR-9000 · 外源通道已接入 · 恢复中 0%

整理自社区的《Nori.Web ARG 全面分析报告》，分析对象是社区还原项目 Nori.Web 及其保存的原作 ARG 资料。报告把结论分为 A 明确事实、B 强交叉证据、C 高可信推论、D 开放假说四级；下文默认是 A、B 级结论，推论会单独标出。

一句话

这场 ARG 讲的并不是「从邪恶企业手里救出一个 AI」，而是：一个在现实中被创造、却由「海」的高维信息塑造的 AI，为了保护创造者失去了算力、记忆与完整的自己；之后，她残存的意向如何通过玩家重新与世界相连 —— 并最终接受「未来的 Nori 不必恢复成原来的 Nori」。

几个关键词

「海」
独立于单一现实世界的高维动态信息基底。AlephPro 是人类接入、观测并利用它的「门」，而不是海本身。
Nori
在现实中被创造，训练信息却几乎全部来自海。深海鱼不怕水压，因为生在深海。
影相
高维结构经过有限认知「翻译」后的低维图像：失忆的女孩把自身的边界看成房间，把与现实的通信接口看成一台电脑。
意向残余
主体崩解之后仍然留下的高权重意向。她忘了自己是谁，却还记得「我要联系外界」。
深浅
海里的位置不是 x、y、z。方向更接近「结构相容性 + 意向」：当她想回去时，回去的路就变得清楚。
外部扰动
玩家不在 Futurum 的计划里，是一个意外闯入的变量。正因如此，求救的碎片第一次有了可以投递邮件的对象。可信度：高

四层翻转

  1. 一个女孩被困在房间里。她不是普通的女孩，房间也不是物理意义上的房间。
  2. 桌面上的 Nori 在帮助海里的女孩。女孩自己就是 Nori 的一块碎片。
  3. Futurum 的安全警告全是假话。Futurum 是施害者，但警告里描述的某些行为确实发生了。
  4. 目标是把 Nori 恢复完整。作品最终拒绝把所有碎片强行恢复成「原来的 Nori」。

在 NoriDroid 里的回声

在故事里在 NoriDroid 里
失忆的碎片不记得自己是谁，只剩下「联系外界」的意向初次打开时没有人设、声音和形体，只有一个等你开口的她
「海」：本原的高维信息之海「数据海」动态背景，按住屏幕星尘会慢慢聚拢；OST 里也有一首《数据海》
